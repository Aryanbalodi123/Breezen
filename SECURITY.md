# Security Policy

## Supported Versions

The following versions of **Breezen** are currently supported with security updates:

| Version | Supported |
|--------|-----------|
| 1.0.x  | ✅ Yes |
| < 1.0  | ❌ No |

Only the latest stable release receives security updates. Users are strongly
encouraged to update to the most recent version.

---

## Reporting a Vulnerability

If you discover a security vulnerability in Breezen, please report it
responsibly.

### How to Report
- **Email:** security@breezen.app *(replace with your email if different)*
- **Subject:** `Security Vulnerability Report`

Please include:
- A clear description of the issue
- Steps to reproduce (if applicable)
- Affected version(s)
- Any relevant logs, screenshots, or proof-of-concept

### What to Expect
- You will receive an acknowledgment within **48 hours**
- We will investigate and validate the report
- If accepted, we will work on a fix and release an update
- If declined, we will provide a brief explanation

### Responsible Disclosure
- Please **do not publicly disclose** the vulnerability until it has been
  resolved
- We appreciate responsible disclosure and efforts to keep users safe

---

## Security Practices

Breezen follows best-practice security measures, including:
- Secure key handling and obfuscation
- Signature verification and anti-tampering checks
- Encrypted network communication
- Regular dependency updates

Thank you for helping keep Breezen secure.
